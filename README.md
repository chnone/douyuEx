# DouyuEx

斗鱼网页增强脚本，运行于 Tampermonkey（油猴）。本仓库由 `chnone` 在原项目基础上继续维护，原作者小淳已于 2026 年 8 月停止更新。

现有功能包括弹幕增强、直播间工具、界面调整等；本分支新增星推金币自动抽奖、粉丝钓鱼周图鉴领奖、鱼娘自动召唤、高级鱼饵购买、积分兑换陪伴印章和全力守护单次赠送等功能。安装后，点击直播间礼物栏下方的精灵球图标打开功能面板。

## 安装与更新

### 一键安装 / 更新

**[点击安装 / 更新 DouyuEx](https://raw.githubusercontent.com/chnone/douyuEx/refs/heads/feat/anchor-star-lottery/install/douyuex.user.js)**

1. 在浏览器中安装并启用 Tampermonkey（油猴）。
2. 点击上面的安装按钮，在油猴页面确认“安装”或“更新”。无需下载源码、安装 Node.js 或自行编译。
3. 如果单独安装过“斗鱼自动抽星推金币”，在油猴管理面板中停用它，保持 DouyuEx 启用。
4. 刷新斗鱼页面，点击精灵球 → 工具条末尾的「活动助手」，选择领奖、抽奖、鱼娘召唤、鱼饵购买、印章兑换或全力守护赠送。面板不加载原活动页面，打开面板不会自动执行。

安装脚本包含本仓库的更新地址。后续发布更高版本后，油猴可按设置自动检查更新，也可以在油猴中手动检查更新，或再次点击上面的按钮。工具条已移除 FKBUFF、代抢红包外链和旧更新入口。

### 安装按钮没有弹出油猴页面

如果浏览器直接显示代码或下载文件，在油猴管理面板的“实用工具”中导入该文件，或将下载的脚本全文粘贴到文本导入区域，再确认安装。

已安装相同版本或更高版本时，无需重复安装。若要给之前手动安装的同版本脚本补上更新地址，可将安装链接中的完整代码复制到油猴的原脚本编辑器中替换并保存（Windows：`Ctrl+S`；macOS：`Command+S`）。若提示重新安装会重置配置，请取消并使用此方法。

按钮未出现时，确认 DouyuEx 已启用、独立抽奖脚本已停用，并刷新直播间。

## 送出今日到期的背包礼物

打开「背包」，在「清空背包」旁点击「送出今日到期」。数字 `0` 表示今天到期，`1` 表示明天，`2` 表示后天。按钮只处理 `0` 的普通可赠送礼物，赠送给当前直播间，不购买礼物。

- 跳过喇叭、改名卡等功能道具；暂只处理已核实的普通赠礼类型，未知类型、特殊业务道具和无法区分的同 ID 多条库存也会跳过。
- 每送 1 个重新读取库存与到期状态，间隔至少 0.5 秒，避免同类礼物混有其他日期的库存时整项送光。可随时点击「停止赠送」。
- 左下角显示已送出的礼物和数量，以及跳过的到期道具项数；重新打开背包查看最新库存。
- 切换房间、账号、隐藏页面或跨天时停止；失败、超时、库存不一致时不自动重试。最后一笔结果不明时，核对库存后刷新再操作。

## 星推金币自动抽奖

在「活动助手」中，直接点击「星推荐积分抽奖」开始（原活动页的“自动抽奖”入口仍可使用）：

- 每 100 金币十连抽，剩余每 10 金币单抽，不足 10 金币保留。
- 每轮抽奖成功后重新读取余额，将中奖返还的金币继续用于抽奖，直至不足 10 金币。例如 1000 金币在整个过程中合计返还 50 金币，可以抽 105 次。
- 点击“停止”后，当前已发出的请求返回即停止。
- 请求失败、超时或返回异常时停止，不自动重试。先核对余额和探索记录，再刷新页面重试。
- 完成后刷新活动页，查看最新余额和探索记录。

打开面板不会自行抽奖。运行中按钮变为「停止星推荐积分抽奖」，再次点击即可停止。关闭面板也会停止本轮，已发出的请求仍等待结果；余额查询失败不会继续抽奖。

## 粉丝钓鱼周图鉴领奖

打开「精灵球 → 活动助手」，直接点击「图鉴领取」。通过官方列表与领奖接口，只领取点击时「我的周图鉴」中已达成且配置了奖励的卡片，跳过未点亮、已领取及无奖励的卡片；不需要打开原活动页。

- 每次只提交一张，等待明确成功后再继续；两张之间随机等待 0.5–2 秒，并重新核对状态，避免重复领取。
- 点击一次只执行一轮，领完即结束，不定时循环。运行期间按钮变为「停止图鉴领取」，每张领取结果与结束汇总使用直播间左下角的插件提示。
- 隐藏页面或关闭助手即停止；结果未确认时不会重试，需刷新核对。
- 只处理「我的周图鉴」，不会自动钓鱼，也不会领取本房图鉴或永久图鉴。

慢速操作不保证免受平台检测或处罚；遇到验证、操作频繁等提示，请停止并按页面要求手动处理。

## 一键续牌与当前房间弹幕

点击精灵球里的「一键续牌」，确认荧光棒数量后，在当前直播间发送一次 `666`，再按原数量给粉丝牌房间赠送背包荧光棒。没有荧光棒也会尝试发送当前房间弹幕；取消对话框不会发送。

- 不赠送全力守护，不向其他粉丝牌房间发送弹幕，不打开其他房间。
- 保留弹幕框已有草稿，这条 `666` 不添加插件小尾巴。登录、禁言及冷却限制仍由页面处理，失败不重试。
- 运行期间重复点击不会启动第二轮；荧光棒逐个提交，等待返回后再继续。
- 左下角提示提交/确认状态；没有收到回执时不显示“发送成功”。

## 鱼娘自动召唤

「精灵球 → 活动助手 → 鱼娘自动召唤」使用钓鱼「我的形象」中的现有召唤机会，不需要打开原活动页面。

- 每轮读取官方最新剩余机会，优先十连、不足十次时单抽；重复形象自动回收返还的机会会继续使用，直到余额为零。
- 每轮间隔 0.5–2 秒，点击运行中的按钮、关闭助手或隐藏页面即可停止后续召唤；已发出的请求仍等待结果。
- 面板及左下角提示累计召唤、回收重复形象、返还机会和剩余机会；原活动页的数据需重新打开查看。
- 失败或超时不重试，先核对召唤记录后刷新。不会购买机会、领取任务或使用需要解锁的百连功能。

## 高级鱼饵三组购买

「精灵球 → 活动助手 → 高级鱼饵 ×3组」一次购买 3 组，每组 300 个，共 900 个高级鱼饵。每组赠送当期对应礼物 4 个，共 12 个，使用现有鱼翅余额，不自动充值。

- 按官方活动配置中的高级鱼饵等级 `baitLv=3` 识别礼物 ID，再通过官方单礼物详情接口读取名称与价格，不写死「招募令」，也不要求活动礼物出现在普通礼物栏。活动与礼物现价不一致，或每组不再是 4 个礼物兑换 300 个鱼饵时停止；实际房间能否赠送仍由官方赠礼接口校验。
- 点击后核价通过就直接购买，不再弹二次确认框；按钮说明明确这是鱼翅付费操作。分 3 笔串行执行，不会因当前选中的是中级鱼饵而改买中级。
- 批次等待从 0.7 秒缩短为 0.35 秒，减少 50%；首笔复用刚读取的报价，后两笔并行读取活动配置与礼物详情，全部核验通过才提交。三组只读查询由 8 次减至 6 次，不并发扣费；实际总耗时仍取决于接口响应。
- 可再次点击停止；关闭助手、隐藏页面、切换账号或房间、跨天都会停止后续购买。已发出的请求无法撤回，仍等待返回结果。
- 失败或超时不自动重试；最后一笔结果不明时锁定按钮，需核对鱼饵库存及消费记录后刷新。

## 积分全换陪伴印章

「精灵球 → 活动助手 → 积分全换陪伴印章」只使用鱼塘商城积分（鱼重量），不花鱼翅，不兑换鱼丸、粉丝牌等其他物品。

- 按当前可兑换印章档位从贵到便宜执行，当前为 250 积分换 50 个、150 积分换 30 个、50 积分换 10 个。贵档次数用完、库存待刷新或余额不足时，再选下一档。
- 每次只兑换一份，成功后等待 0.5 秒并重读商城余额及可兑换状态，不把配置总库存当成个人每日额度，不写死每日次数。
- 本轮最多花掉点击时已有的积分，不追着过程中新增的积分继续兑换。因限购或不足最低档剩下的积分会保留，并显示已兑换数量、消耗和余额。
- 支持停止、关闭助手停止和重复点击保护；账号、房间、日期变化或余额变化不符时停止，不自动重试未知结果。

## 弹幕快捷操作

播放器内选中弹幕后，操作栏按两列排列：第一排固定「直接回复」「+1」，其余原生操作保持原有顺序，从第二排起每排两个，更多功能继续向下排。某个直播间未开放原生回复时，直接回复显示为不可用，不猜测作者或绕过限制。保留原生按钮与已有回复、草稿保护逻辑；弹窗根据播放器边界调整位置，避免贴边时被裁切。

## 全力守护

「精灵球 → 活动助手 → 赠送全力守护 ×1」是独立的付费操作，只向当前直播间赠送 1 个（官方礼物 ID 24478）。不会随打开面板或一键续牌自动赠送。

- 点击后重新读取官方礼物列表，核对名称、ID、可赠送状态及鱼翅价格；单次上限 1 鱼翅（约 1 元），超过上限或无法核价不发送。
- 赠送过程中按钮禁用，连续双击不会重复提交；失败、超时或不明确响应不自动重试，需先核对消费记录。
- 关闭助手或隐藏页面会取消尚未提交的赠送；已提交的付费请求不能撤回，仍等待结果并显示提示。
- 使用现有鱼翅余额，余额不足由平台返回失败，不自动充值。

## 开发与发布

当前功能位于 `feat/anchor-star-lottery` 分支，`master` 暂未包含。开发需要 Node.js（带 npm）和 Git：

```sh
git clone --branch feat/anchor-star-lottery https://github.com/chnone/douyuEx.git
cd douyuEx
npm ci
npm test
npm run build
```

功能模块位于 `src/packages/`，页面路由位于 `src/routers/router.js`。本地构建输出在 `dist/`，完整安装文件为 `dist/douyuex.user.js`；`src/main.js` 只是源码入口，不能直接安装。

发布更新时：

1. 同步提高 `src/main.js` 的 `@version` 和 `src/packages/Update/Update.js` 的 `curVersion`。
2. 执行 `npm test` 和 `npm run release`，生成 `install/` 中的安装脚本、更新元数据和版本文件。
3. 将源码及 `install/` 产物一并提交并推送到 `feat/anchor-star-lottery` 分支；README 的安装按钮和油猴更新地址会指向新版本。

`npm run build` 仅生成本地产物；`npm run release` 会同时刷新待发布文件，但不会自动推送。发布前请确认工作区修改已准备好发布。

测试使用模拟接口，不会消耗真实金币。实际活动接口仍需在登录后的页面验证。
